# PortFree — Mac App Store Edition Privacy Policy

Effective October 5, 2026. Developer: JINGZHE JIANG.

PortFree is a local, sandboxed macOS utility that generates shell commands for TCP ports. It does not execute those commands or inspect running processes.

## Data collection
PortFree does not collect, transmit, sell, or share personal information. It has no accounts, advertising, analytics, tracking SDKs, or network features.

## Local operation and clipboard
Port numbers and recently copied port selections are held in memory during the app session. Clicking Copy writes the generated command to the macOS clipboard. PortFree does not read the clipboard. Clipboard content is then subject to macOS and any clipboard tools you choose to use.

## Commands you run
You can independently paste and execute a generated command in Terminal. Terminal output and operating-system actions remain under your control. PortFree does not receive command output or execution history and does not request administrator access.

## Support
If you email support, we receive the information you voluntarily include and use it to respond. Avoid sending passwords, API keys, or other sensitive information. Apple may separately process store, purchase, or diagnostic information under Apple's privacy policies.
